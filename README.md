# Telegram Unlock

Утилита для обхода замедлений и блокировок Telegram Desktop на ПК.

## Как это работает
- Автоматически находит установленный Telegram Desktop.
- Опрашивает скоростные серверы обхода (Fake-TLS MTProto) и измеряет задержку (пинг).
- Запускает Telegram с подключением к самому быстрому серверу.

## Сборка
Для сборки не требуется устанавливать сторонние библиотеки — используется встроенный в Windows компилятор C#:
```cmd
build.bat
```

## Использование
Запустите `TelegramUnlock.exe` и нажмите **Запустить**.
